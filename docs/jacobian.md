# 三种雅可比矩阵的转换

> 学习笔记。对应实现：`expendlib/core.py`
> 记号约定：`T_sb` = 物体坐标系 `{B}` 相对于空间坐标系 `{S}` 的齐次变换，
> `T_bs = T_sb⁻¹`，`[Ad_T]` 为 6×6 伴随矩阵。

---

## 1. 三种雅可比的定义

设关节角 `q ∈ Rᴺ`，末端执行器位姿 `T(q)`。

| 名称 | 记号 | 定义式 | 速度所在坐标系 |
|------|------|--------|----------------|
| 空间雅可比 | `Js` | `V_s = Js(q) q̇` | 空间系 `{S}`，取末端当前位姿处的旋量 |
| 物体雅可比 | `Jb` | `V_b = Jb(q) q̇` | 物体系 `{B}`，固连在末端上 |
| 几何雅可比 | `Jg` | `V_g = Jg(q) q̇` | `{S}` 中的 **ω** + **末端原点的实际线速度** |

三者都是 6×N，都满足 `V = J q̇`，区别只在 **V 用哪个坐标系、哪个参考点表达**。

```
V = [ ω ]      角速度部分（向量，换系只需左乘旋转矩阵）
    [ v ]      线速度部分（依赖参考点，换点要加 ω × p 修正）
```

---

## 2. 转换关系

### 2.1 Js ↔ Jb：换坐标系（伴随矩阵）

旋量换系公式 `V_s = [Ad_Tsb] V_b`，两边同乘 `q̇`：

```
Jb = [Ad_Tbs] · Js          Js = [Ad_Tsb] · Jb
```

实现：`Js2Jb()` / `Jb2Js()`，用 `mr.Adjoint` 与 `mr.TransInv`。

> 伴随矩阵把"整条旋量"从一个系搬到另一个系，**不改变参考点**。

### 2.2 Js → Jg：换参考点到末端原点

空间系下旋量 `V_s = [ω_s; v_s]` 中的 `v_s` 是对 **{S} 原点** 定义的。
末端原点当前位于 `p = T_sb[:3, 3]`，该点的实际线速度为

```
v_p = v_s + ω_s × p = v_s − p̂ ω_s          (p̂ = [p]×)
```

写成分块矩阵：

```
Jg = [ I     0 ] · Js
     [ −p̂    I ]

        ┌              ┐
   p̂ =  │  0  −pz   py │
        │  pz  0   −px │
        │ −py  px   0  │
        └              ┘
```

实现：`Js2Jg()`。物理含义：`Jg q̇ = [ω_s; 末端原点实际速度]`。

### 2.3 Jb → Jg：从物体系转回空间系

`V_b = [ω_b; v_b]`，其中 `v_b` 就是末端原点的速度（B 系原点即末端原点），
只需把两个向量都旋转到 `{S}`：

```
Jg = [ R_sb    0   ] · Jb
     [   0   R_sb  ]
```

实现：`Jb2Jg()`。

### 2.4 两条路径殊途同归

```
            Js ──────────────┐
             │               │
   Js2Jg     │               │  Js2Jb
             ▼               ▼
            Jg ◀──── Jb ─────┘
                     │
                  Jb2Jg
```

即 `Js2Jg(Js, T) ≡ Jb2Jg(Js2Jb(Js, T), T)`，数值上应完全一致 —— 可用作自检。

## 3. 解析雅可比 Ja（基于指数坐标）

前面三种都是"旋量形式"的雅可比。**解析雅可比**把速度写成指数坐标
`θ ∈ R³`（旋转向量）的导数形式，用于基于指数坐标的误差与牛顿法求解。

关键工具是 SO(3) 的**左/右雅可比**（把 `θ` 的微分映射到 `ω`）：

```
A_r(θ) = I − (1−cosθ)/θ² · θ̂ + (θ−sinθ)/θ³ · θ̂²      右雅可比  →  A_of_r()
A_l(θ) = I + (1−cosθ)/θ² · θ̂ + (θ−sinθ)/θ³ · θ̂²      左雅可比  →  A_of_l()
```

两者关系 `A_l(θ) = A_r(−θ)`，`θ → 0` 时都退化为单位阵（代码里 `nr < 1e-10`
分支即处理此极限）。

### 3.1 物体雅可比 → 解析雅可比

```
      ┌ A_r(r)⁻¹    0  ┐
Ja =  │               │ · Jb          r = log(R_sb) = so3ToVec(MatrixLog3(R_sb))
      └    0      R_sb ┘

实现：Jb2Ja_r()
```

### 3.2 空间雅可比 → 解析雅可比

```
      ┌ A_l(r)⁻¹     0 ┐
Ja =  │                │ · Js          同上 r = log(R_sb)
      └ −p̂          I  ┘

实现：Js2Ja_r()
```

> 注意两者用的 `A` **不同**：`Jb` 路径用右雅可比 `A_r`，`Js` 路径用左雅可比
> `A_l`；线速度块的处理也与 §2.2 一致（`Js` 路径带 `−p̂` 修正）。

## 4. 可操作度指标 μ1 / μ2 / μ3

对 `J` 做奇异值分解 `J = U Σ Vᵀ`，记 `σ_max`、`σ_min`：

| 指标 | 公式 | 含义 | 实现 | 理想值 |
|------|------|------|------|--------|
| μ1 | `σ_max / σ_min` | 椭球长短轴比 | `mu_1_axis_ratio()` | → 1 |
| μ2 | `(σ_max / σ_min)²` = `cond(JJᵀ)` | 条件数，各向同性程度 | `mu_2_condition_number()` | → 1 |
| μ3 | `∏ σᵢ` = `√det(JJᵀ)` | 椭球体积（方阵时） | `mu_3_volume()` | 越大越好 |

- `σ_min → 0` 即**奇异位形**，μ1、μ2 → `inf`（代码用 `1e-12` 阈值判定）。
- μ3 → 0 同样意味着该方向丧失运动能力。

## 5. 与 modern_robotics 库对照

| 本库函数 | modern_robotics 对应 |
|----------|----------------------|
| `Robot.FK` | `mr.FKinSpace(M, S, θ)` |
| `Robot.IK_n` | `mr.IKinSpace(S, M, T, θ₀, eω, ev)` |
| `Js2Jb` / `Jb2Js` | `mr.Adjoint(T)` + `mr.TransInv(T)` |
| `A_of_r` / `A_of_l` | （未内置，需自己实现） |
| `Jb2Ja_r` 中的 `r` | `mr.so3ToVec(mr.MatrixLog3(R))` |

`mr.JacobianSpace` / `mr.JacobianBody` 可直接算出 `Js` / `Jb`，
再用本库函数转换成 `Jg` / `Ja`。
